# Manage GitHub Issues

## Objetivo
Convertir trabajo conversado en issues chicos, verificables y asignados utilizando GitHub CLI (gh issue).

## Instrucciones
1. Para crear un issue, genera un título descriptivo y un body claro con el contexto necesario.
2. Usa gh issue create --title "..." --body "..." para crearlo en el repositorio.
3. Si hay que listar issues abiertos, usa gh issue list.
4. Manten los issues concisos y modulares.
